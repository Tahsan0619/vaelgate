# Vaelgate

Rise of the Guild. Low-poly action RPG and dungeon crawler with a city hub. Built with Three.js.

## Run

```bash
npm install
npm run build
```

Open `index.html` in a browser (or serve the folder with any static server).

## Develop

```bash
npm run watch
```

## Stack

- Three.js
- esbuild
